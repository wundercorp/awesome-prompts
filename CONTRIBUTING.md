# Contributing to awesome-prompts

Thanks for contributing.

## Primary principle

Every prompt in this repository should be easy to copy and paste into **[BuilderStudio](https://builderstudio.dev/)** for a one-shot run.

## Directory structure

```text
prompts/<category>/<slug>/
  prompt.md
  prompt.json
```

## Required files

### `prompt.md`

The full prompt body.

### `prompt.json`

Metadata for the prompt. Required fields for every entry:

- `title`
- `slug`
- `category`
- `summary`
- `builderstudio_url`
- `usage`
- `tags`

Required field for **new prompt submissions in pull requests**:

- `demo_url`

Default seeded prompts may omit `demo_url`. New community prompt PRs may not.

## Demo URL rule

Every new prompt added in a pull request must include a public demo link in `prompt.json`:

```json
{
  "demo_url": "https://example.com/demo"
}
```

The demo should show the result produced by the prompt, ideally generated by running the prompt in **BuilderStudio**.

## Contribution steps

1. Create a new directory in the appropriate category.
2. Add `prompt.md` and `prompt.json`.
3. Include `demo_url` in `prompt.json`.
4. Run:

```bash
npm install
npm run validate
npm run generate:readme
npm run validate:pr
```

5. Open a PR.

## Quality bar

- Prompt should be usable as a one-shot input.
- Prompt should be clear, complete, and production-oriented.
- Summary should explain what gets built.
- BuilderStudio should be the primary execution destination.
- New prompt submissions should include a working demo link.
